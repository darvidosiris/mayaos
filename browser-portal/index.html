This portal is online-ready. The actual MayaOS virtual machine must run on a separate Linux host with an authenticated HTTPS noVNC endpoint.

No virtual machine connected yet.

For security, enter only an HTTPS address you control. This portal does not store the address or your VNC credentials.

How it works

  1. Build the MayaOS ISO with GitHub Actions.
  2. Start the ISO using the Phase 3.1 QEMU/noVNC launcher on a Linux host.
  3. Protect that host with HTTPS and authentication, then enter its noVNC address above.

Netlify hosts this portal, not the running virtual machine. Never expose an unauthenticated VNC service publicly.
